## Fix round 1 (coordinator review findings F1-F5)

All changes confined to `studio/tools/inject_asset.mjs`, `studio/test/fixtures/make_fixture.mjs`, `studio/test/inject.test.mjs`, and `studio/.gitignore`.

### F1 (Important) — normals/tangents not baked, only POSITION

Added a `normalMatrix3(wm)` helper: for a column-major 4x4 world matrix, it returns the row-major 3x3 `cofactor(M)/det(M)`, which is algebraically identical to `transpose(inverse(M))` for the linear (rotation+scale) part — this avoids a separate transpose step. The bake pass now, per primitive:
- `NORMAL`: transforms each vector by the normal matrix, then renormalizes (`/= hypot(...)`, guarding against a zero-length degenerate result with `|| 1`).
- `TANGENT`: transforms the `xyz` by the same 3x3 as POSITION (a tangent is a direction vector, not a normal — it transforms with `M` itself, not `M`'s inverse-transpose), renormalizes `xyz`, and leaves `w` (handedness) untouched.
- Both are skipped entirely when the primitive has no such attribute.

### F2 (Important) — shared mesh/accessor double-baking

Before baking, the code now counts how many nodes reference each `Mesh` (`meshNodeCounts`). For any mesh referenced by more than one node, every occurrence after the first gets `node.setMesh(cloneMeshDeep(doc, mesh))` — a new `Mesh` with new `Primitive`s and, critically, **cloned** `POSITION`/`NORMAL`/`TANGENT`/indices `Accessor`s (via `accessor.clone()`, which gltf-transform deep-copies the underlying typed array — confirmed by reading `Property.copy()` in `@gltf-transform/core`'s source, which calls `.slice()` on any `ArrayBuffer`/typed-array attribute). This guarantees each node instance bakes into its own vertex data instead of double-applying (or last-write-clobbering) a shared accessor.

As defense-in-depth (per the instruction), the bake pass and the scale/re-origin pass each keep their own `Set` (`bakedPosition`/`bakedNormal`/`bakedTangent` for the bake pass, `scaledPosition` for the second pass) and skip any accessor already present in the set — so even an accessor that ends up referenced twice for some other reason is never baked/scaled twice.

No dedicated multi-node-sharing fixture was added (not requested in F5's test list), but the mesh-cloning path was sanity-checked by construction (reading gltf-transform's `Property.copy()`/`clone()` semantics directly rather than assuming).

### F3 (Important) — `triCount` assumed TRIANGLES

`triCount` is now exported and mode-aware: mode 4 (`TRIANGLES`) → `n/3`; mode 5 (`TRIANGLE_STRIP`) and mode 6 (`TRIANGLE_FAN`) → `max(0, n-2)`; every other mode (points/lines/line-loop/line-strip) → `0`. `n` = index count if the primitive has indices, else vertex (POSITION) count. Verified the WebGL-enum mode values directly against `@gltf-transform/core`'s compiled source (`Primitive.Mode`: `POINTS=0, LINES=1, LINE_LOOP=2, LINE_STRIP=3, TRIANGLES=4, TRIANGLE_STRIP=5, TRIANGLE_FAN=6`).

### F4 (Minor) — non-positive height/scale silently used scale 1

Added `if (height !== undefined && !(height > 0)) throw new Error('--height must be > 0')` and the same check for `scale`, run up front (before reading the input file) alongside the existing `--as` shape validation.

### F5 — new fixtures and tests

- `make_fixture.mjs` now also writes `test/fixtures/fixture_rot.glb`: the same 24-segment, radius-0.5, height-4 prism (wall only, no extra budget-busting cap triangles), but with a real per-vertex radial `NORMAL` attribute (`(cos a, 0, sin a)`), parented under a node with `translation [3,1,0]` and `rotation [sin45, 0, 0, cos45]` (90° about X, `Math.SQRT1_2` for both components).
- Derived the expected post-bake numbers analytically rather than guessing: a +90° rotation about X maps a local point `(x,y,z) -> (x,-z,y)`. The prism's local Y axis (extent 4, the height) lands on world Z; the local Z-radial offset (extent 1, i.e. `[-0.5,0.5]`) lands on world Y; local X-radial (extent 1) stays on X. So after baking, extents are X≈1, Y≈1, Z≈4 — and since `height:1` scales by the *new* Y extent (1.0), `s=1`, leaving those extents unchanged. Radial normals `(nx,0,nz)` transform the same way to `(nx,-nz,0)` — the baked Z component of every wall normal must be ≈0, which is exactly the signal that would catch an unrotated-normal bug (a bug that left normals in the original `(cos a, 0, sin a)` frame would show `|n.z|` values up to 1, not <0.05).
- Added to `studio/test/inject.test.mjs`:
  - `'bakes a node rotation (90deg about X) into POSITION and NORMAL, not just translation'`: injects `fixture_rot.glb` with `height: 1`, asserts Y extent ≈1, X extent ≈1, Z extent ≈4 (1 decimal, since it's an unscaled value derived from a 24-gon approximation of a circle — the radius-based extents are exact but I left one decimal of slack on the Z assertion for float accumulation), every `NORMAL` is unit length (±1e-3 via `toBeCloseTo(1,3)`), and every `NORMAL`'s Z component has `|nz| < 0.05`.
  - `'triCount is mode-aware for TRIANGLE_STRIP (n-2 triangles, not n/3)'`: builds a synthetic `Document` with a 10-vertex, no-index, mode-5 primitive and asserts `triCount(doc) === 8`.
  - `'rejects a non-positive height'`: `height: 0` → rejects `/--height must be > 0/`.
- `.gitignore` changed from `test/fixtures/fixture.glb` to `test/fixtures/*.glb` (covers both fixtures); `beforeAll` now regenerates if **either** `fixture.glb` or `fixture_rot.glb` is missing.
